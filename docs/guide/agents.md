# Агенты и вопросы

Агент — настоящий адаптер по [ACP](https://agentclientprotocol.com/): `claude`,
`codex` или произвольная ACP-команда. Реестр — в разделе «Агенты», там же видно,
**запустится ли агент на этой машине**, — раньше, чем это выяснится на карточке.

## Установка

```sh
npm install -g @agentclientprotocol/claude-agent-acp
npm install -g @agentclientprotocol/codex-acp
```

Если есть Node.js (для Vibe — uv), адаптер можно поставить прямо в разделе
«Агенты» кнопкой «Установить»: он ляжет в папку приложения. Запуски берут
установленную версию и в реестр не ходят, поэтому новая версия появится только
после кнопки «Обновить». Адаптер, поставленный вами глобально, приложение не
трогает.

Нужна ваша подписка на Claude или Codex: приложение ничего не покупает и никуда
ничего не отправляет само.

## Когда агент спрашивает

Вопрос агента — разрешить ли действие или уточнить что-то — приходит сразу
тремя дорогами, но вопрос это один и тот же:

- **системным уведомлением**, с вариантами прямо на нём;
- в панели **«Требуют внимания»**;
- на самой карточке.

Ответить можно где угодно из трёх: вариантом, который предложил агент, своими
словами или кнопкой **«Отказать»** — отказ агент воспримет как «нет» и продолжит
без этого.

::: tip macOS
Уведомления работают только из собранного `.app`. Запущенный напрямую бинарник
их выключает и пишет об этом в лог — ничего при этом не теряется: уведомление
всегда лишь вторая дорога к ответу.
:::
